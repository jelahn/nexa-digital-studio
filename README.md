# NEXA Digital Studio website

A responsive, single-page starter website for NEXA Digital Studio, a proposed digital content studio serving home improvement contractors.

## Preview
Open `index.html` in a browser.

## Before publishing
1. Replace `REPLACE_WITH_BUSINESS_EMAIL` in the JavaScript with the real business inbox.
2. Connect the contact form to a real form endpoint or CRM if you prefer not to use the visitor's email app.
3. Verify the business name and domain availability; this is a proposed brand concept, not a trademark clearance.
4. Confirm service scope, package pricing, turnaround times, revisions, privacy terms, and any applicable legal requirements.
5. Add real portfolio examples only with permission. Current design uses original CSS artwork and no fabricated client results.

## Files
- `index.html` — complete responsive website (HTML, CSS, JavaScript in one file).
